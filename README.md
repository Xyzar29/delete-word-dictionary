# Delete Word Dictionary

Entry for [The Word You'd Delete From the Dictionary](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) on [make.fun](https://make.fun).

## The word

**goodbye**

Erase it and nobody can ever leave. Every farewell, every exit, every
"goodbye" at the end of a call is gone, so the whole world is stuck at the
party forever. A real word everyone recognises, funny the instant it is
gone, and a pick the rest of the field is unlikely to reach for first.

## How it works

`main.ts` (Node 22) writes the single word to `/output/entry.txt` — exactly
one word, no trailing newline, nothing added around it — after checking it
against the gate (1 to 77 characters, not only white space, exactly one word).

```sh
node main.ts
cat /output/entry.txt
```
